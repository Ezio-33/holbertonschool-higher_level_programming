# Python - Tout est Objet

## Objectifs d'Apprentissage

À la fin de ce projet, tu devrais être capable d'expliquer à quiconque, sans l'aide de Google :

- Qu'est-ce qu'un objet ?
- Quelle est la différence entre une classe et un objet ou une instance ?
- Quelle est la différence entre un objet immuable et un objet muable ?
- Qu'est-ce qu'une référence ?
- Qu'est-ce qu'une affectation ?
- Qu'est-ce qu'un alias ?
- Comment savoir si deux variables sont identiques ou liées au même objet ?
- Comment afficher l'identifiant d'une variable (qui est l'adresse mémoire dans l'implémentation CPython) ?
- Quels sont les types muables et immuables intégrés ?
- Comment Python passe-t-il les variables aux fonctions ?

## Exigences

- **Scripts Python** :
  - Éditeurs autorisés : `vi`, `vim`, `emacs`
  - Tous tes fichiers seront interprétés/compilés sur Ubuntu 20.04 LTS en utilisant python3 (version 3.8.5)
  - Tous tes fichiers doivent se terminer par une nouvelle ligne
  - La première ligne de tous tes fichiers doit être exactement `#!/usr/bin/python3`
  - Un fichier `README.md`, à la racine du dossier du projet, est obligatoire
  - Ton code doit utiliser le style `pycodestyle` (version 2.7.\*)
  - Tous tes fichiers doivent être exécutables
